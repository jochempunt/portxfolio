# Departures

<Linkbutton  label="View Website" href="https://ov-app-ten.vercel.app/" icon="external" />  
<Linkbutton label="View Code on Github" href="https://github.com/jochempunt/ovApp/" icon="github" />  


A mobile-first web app for checking Dutch public transport departures. I made this because I got annoyed losing time with official apps, especially when I'm in a hurry and just need to know if and when my next bus is coming. One tap, easily bookmarkable or installable as a PWA.


## Key features
- Live departure data from the OV-API (metros, buses, trams)
- Searchable stops, sorted by town & stop name 
- Mobile-first responsive design with multiple custom themes
- Client-side caching and background refresh using TanStack Query
- PWA (Progressive Web App) support for offline use and home screen installation
- Shareable links—stops encoded in URL (e.g `?stop=MttAca`) for easy bookmarking and sharing

- React (Vite)

- OV-API (public transport data)
- MUI component library
- Deployed on Vercel
